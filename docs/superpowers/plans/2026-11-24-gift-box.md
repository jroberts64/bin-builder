# Vine Gift Box Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Node script that generates the print files for the marble-and-wood Vine gift box. It produces a fit test first, then the base, the 3-part lid with embedded-tulle pause, the wood frame, a tulle cutting template, and a README.

**Architecture:** A standalone ES-module script tree under `scripts/gift-box/`, separate from the React app. All solids are built with `manifold-3d` (already a repo dependency, v3.5.1) in **print pose, Z-up, mm**. Each part module returns Manifold solids. Writers turn them into binary STL, plain 3MF, or a Bambu-flavoured multi-part 3MF. Tests use `node:test` and call the builders directly.

**Tech Stack:** Node 23 (ESM `.mjs`), `manifold-3d` 3.5.1 (`Manifold`, `CrossSection`), `node:test`, `node:assert/strict`. No new dependencies. Write the ZIP/CRC32 writer inline (the repo's rule: no JSZip).

**Spec:** `docs/superpowers/specs/2026-11-24-gift-box-design.md`. Visual reference: the artifact linked there, whose `vineParts()` and `ovalFrame()` code fixes the vine composition and frame profile.

## Global Constraints

- Inside cavity **165 × 125 × 45**: floor top to lid underside.
- Outer **171.4 × 131.4**, corner radius **10**, walls **3.2**, floor **2.4**, lid top **2.4**, lid skirt **1.6** thick, lid total height **14**. Lid outer top face at assembled z = **49.8**.
- Shoulder at z = **35.8**. Collar **1.4** thick, inner face flush with the cavity, top at z = **47.1**, with a lead-in chamfer of 0.4–0.8.
- Skirt-to-collar clearance **0.2/side**. Crush ribs: **8**, **1.0** wide, half-round, standing **0.2 + interference** proud of the collar. They run from shoulder + 2 to collar top − 1, with a tapered lead-in at the top. Default interference **0.10**, fit-test values **0.05 / 0.10 / 0.15**.
- Chamfer **0.6** on the base bottom outer edge, and **0.6–0.8** on the lid top outer edge (the lid's bed edge).
- Window ellipse semi-axes **63.7 × 44.7**, centred. Tulle plane **1.16** above the lid's bed face. Tulle cut = window + **8** all round.
- Lid pin holes: 4 × **Ø1.95 × 0.9** deep in the lid's bed face. Frame pin holes: 4 × **Ø1.95 × 1.5** deep in the frame underside. Both on the frame-band midline (window + 5) at 0°/90°/180°/270°. Pins are 1.75 filament, about 2.2 long.
- Frame inner edge at window − 1, width **12**, peak height **5.8**, profile as the artifact's `ovalFrame()`, no overhangs.
- Window contents span the full plate thickness (0 → 2.4). Parts **abut, never overlap**. Minimum solid feature **1.0**, minimum slot **0.8**.
- Output dir `~/Downloads/gift-box/`. Filenames are exactly those in the spec's Output table.
- Every part must fit a **256 × 256** bed. No supports. 0.4 nozzle, 0.2 first layer, 0.12 layers.
- Filaments: White Marble = base, lid body, petals. Mistletoe Green = vine. Silk+ Gold = flower centres. Rosewood = frame.
- Manifold leaks WASM memory (CLAUDE.md). Each test file builds its parts once and shares them across its tests; don't rebuild per assertion.

## Review Focus

1. **The slicer ignores our Bambu metadata.** The user then gets a lid with all 3 parts on one filament and no pause. Expected: the README alone is enough to set up both by hand. Task 6 tests README content regardless of the metadata route.
2. **Pause height off by a layer.** Pausing one layer early or late either buries the tulle below the vine's lower half or leaves the vine's top half printing in air. Expected: the pause sits exactly at the 1.16 layer boundary, and the README states both layer number and height. Task 6 asserts the number is consistent with 0.2 + 0.12·k.
3. **The fit-test label doesn't match its geometry.** The user would then pick the wrong interference. Expected: each piece's measured rib-overlap volume rises with its label. Pinned in Task 2.
4. **Vine or petal islands touching each other or the body by overlap.** The slicer would then assign the overlap arbitrarily and the colour bleeds. Expected: pairwise intersection volumes ≈ 0. Pinned in Task 4.
5. **`--interference` flag given a silly value.** Expected: values outside 0–0.3 are rejected with a clear message, not silently built. Pinned in Task 7.

### Task 1: Kernel — CSG init, 2D shapes, checks and writers

**Files:**
- Create: `scripts/gift-box/kernel.mjs`
- Test: `scripts/gift-box/test/kernel.test.mjs`

**Interfaces:**
- Produces:
  - `initKernel(): Promise<{ Manifold, CrossSection }>`. Loads `manifold-3d`, calls `setup()` once, caches the result.
  - `roundedRect(w, d, r, segs?): number[][]`, a CCW polygon centred on the origin.
  - `ellipse(rx, ry, segs?): number[][]`, CCW.
  - `prism(polygons, z0, z1): Manifold`, an extrusion of a `CrossSection`.
  - `chamferedPrism(poly, z0, z1, chamferBottom, chamferTop): Manifold`, a 45° chamfer built as a hull or loft of the inset outline.
  - `edgeCheck(manifold): { open: number, nonManifold: number }`, an **exact index-based** check on `getMesh()`.
  - `volume(m): number`, and `overlapVolume(a, b): number`, which is `a.intersect(b).volume()`.
  - `toSTL(manifolds: Manifold[]): Uint8Array`, binary, combined.
  - `zipStore(entries: {name, data: Uint8Array|string}[]): Uint8Array`, stored, with CRC32.
  - `write3MF(objects: {name, manifold}[]): Uint8Array`, plain, one `<object>` per entry, mm units.

- [ ] **Step 1: Write failing tests**: `kernel.test.mjs`
  - `edgeCheck` of a 10 mm cube prism is `{open: 0, nonManifold: 0}`.
  - `volume(prism([roundedRect(20, 10, 0)], 0, 5))` ≈ 1000 (±0.01).
  - `toSTL([cube]).length === 84 + 50 * triangles`.
  - `overlapVolume` of two 10 mm cubes offset 5 in x ≈ 500.
  - The bytes `write3MF` produces, written to a temp file, pass `unzip -t` (via `execFileSync`). The model XML contains `unit="millimeter"`, and there is one `<object` per input.
  - `chamferedPrism` with a 1 mm bottom chamfer has a bottom face 2 mm smaller in each dimension (measured from `boundingBox` of a 0.01-thick slice at z = 0).
- [ ] **Step 2: Run `node --test scripts/gift-box/test/`.** Expected: FAIL (module missing).
- [ ] **Step 3: Implement `kernel.mjs`.** Import Manifold the same way `paper-stl.mjs` is run, with ESM `import Module from 'manifold-3d'`. Check the package's node entry if that import fails. For the chamfered prism, hull the bottom inset slice with the full outline: `Manifold.hull` of the two thin prisms works for convex outlines (all ours are). Write the CRC32 table inline.
- [ ] **Step 4: Run the tests.** Expected: PASS.
- [ ] **Step 5: Commit** `scripts/gift-box/kernel.mjs scripts/gift-box/test/kernel.test.mjs`, message "gift-box: CSG kernel, checks and writers".

### Task 2: Dimensions, base, lid shell and the fit test

**Files:**
- Create: `scripts/gift-box/dims.mjs`, `scripts/gift-box/base.mjs`, `scripts/gift-box/lid.mjs` (shell only in this task), `scripts/gift-box/fittest.mjs`
- Test: `scripts/gift-box/test/fit.test.mjs`

**Interfaces:**
- Consumes: Task 1 kernel.
- Produces:
  - `DIMS` (frozen object, every Global Constraints number, plus derived `outerW = 171.4`, `outerD = 131.4`, `seat = 47.4`, `topZ = 49.8`, `shoulder = 35.8`, `collarTop = 47.1`, `win = {rx: 63.7, ry: 44.7}`).
  - `buildBase({ interference }): { body: Manifold, ribs: Manifold }`, in print pose (floor on z = 0). `body` excludes the ribs, and the union of the two is the printed base.
  - `buildLidShell(): Manifold`, in print pose: top plate z 0–2.4 on the bed, skirt rising to z = 14. It includes the window hole and pin holes but no vine.
  - `lidToAssembled(m): Manifold`, which is `rotate([180, 0, 0])` then translate so the outer top face sits at z = 49.8.
  - `buildFitTest(): { base: Manifold, lids: { interference, manifold }[] }`. Each piece is a corner section clipped by a box: about 40 mm along each wall from the corner, z from shoulder − 4 to collar top. Each lid piece has its interference debossed as "1" / "2" / "3" (simple bar digits are fine) on its outer face, and the base piece also carries one rib per face.

- [ ] **Step 1: Write failing tests**: `fit.test.mjs`. Build once at the top:
  - `edgeCheck` 0/0 on base body ∪ ribs, the lid shell, and every fit-test piece.
  - Cavity: a probe block 164.9 × 124.9 from z = 2.41 to 47.39 has `overlapVolume` 0 with the base and the assembled lid. A 165.3 × 125.3 probe over the same z range has an overlap > 0.
  - Outer bbox of the base union is 171.4 × 131.4 (±0.01), its max z is 47.1, and min z is 0.
  - `overlapVolume(lidToAssembled(lidShell), base.body)` < 1e-3.
  - `overlapVolume(lidToAssembled(lidShell), base.ribs)` ≈ 8 × ribLength × interference-segment area, within 15%. Rib count is 8, determined as the number of connected components of `ribs`.
  - Fit test: rib overlap volume is strictly increasing across the 0.05 / 0.10 / 0.15 pieces. Each piece is ≤ 60 × 60 mm.
  - The bottom outer edge of the base is chamfered. At z = 0.01 the footprint is about 1.2 smaller than at z = 1.
- [ ] **Step 2: Run the tests.** Expected: FAIL.
- [ ] **Step 3: Implement `dims.mjs`, `base.mjs`, `lid.mjs` (shell), `fittest.mjs`.** Ribs are half-round cylinders (radius = 0.5 at a 1.0 width, centred so they stand 0.2 + interference proud of the collar face). The lead-in is the top 2 mm, hulled to zero protrusion. Placement: 2 per face at ±1/4 of the face's straight length. The collar lead-in chamfer is on its top **outer** edge.

### Task 4: Vine, petals and flower centres

**Files:**
- Create: `scripts/gift-box/vine.mjs`
- Test: `scripts/gift-box/test/vine.test.mjs`

**Interfaces:**
- Consumes: `DIMS.win`, kernel.
- Produces: `buildWindowParts(): { vine: Manifold, petals: Manifold, centres: Manifold }`, each z 0–2.4 in lid print pose. The composition ports the artifact's `vineParts(rx, ry)` (stem S-curve, alternating leaves with vein slots, 2 spiral tendrils, 3 five-petal flowers) to 2D polygons → `CrossSection` → extrude. The stem is clipped to the window ellipse. `petals` = petal discs − `centres`.

- [ ] **Step 1: Write failing tests.**
  - `edgeCheck` 0/0 on each of the three.
  - Pairwise `overlapVolume` < 1e-3 for vine/petals, vine/centres and petals/centres. `overlapVolume` of each with `buildLidShell()` < 1e-3.
  - Every vertex of `centres` and `petals` lies inside the window ellipse scaled by 0.99. `vine` vertices lie inside the ellipse scaled by 1.0001.
  - The vine touches the shell. Grow the vine by 0.05 with `CrossSection.offset` before extruding, and `overlapVolume` with the shell is now > 0.
  - Minimum feature: for each part, `CrossSection.offset(-0.5)` then `offset(+0.5)` keeps ≥ 97% of the area. That proves no feature is narrower than 1.0.
  - Minimum slot: each leaf's vein slot is ≥ 0.8 wide. Assert from the construction parameters exported as `VEIN_WIDTH`.
- [ ] **Step 2: Run.** Expected: FAIL.
- [ ] **Step 3: Implement `vine.mjs`.** Do the 2D union of stem + leaves + tendrils with `CrossSection.union` before extruding. That avoids coplanar overlapping shells (CLAUDE.md rule).
- [ ] **Step 4: Run.** Expected: PASS.

### Task 5: Frame

**Files:**
- Create: `scripts/gift-box/frame.mjs`
- Test: `scripts/gift-box/test/frame.test.mjs`

**Interfaces:**
- Consumes: `DIMS`, kernel, `buildLidShell`, `lidToAssembled`.
- Produces:
  - `buildFrame(): Manifold`, in print pose (flat underside on z = 0). It's a swept closed mesh of the artifact's `ovalFrame()` profile around the ellipse (rx − 1, ry − 1), built manifold-by-construction and passed to `Manifold.ofMesh`, minus 4 pin holes.
  - `frameToAssembled(m): Manifold`, which sits the frame on the lid's top face (z = 49.8).
  - `pinsAssembled(): Manifold`, four Ø1.75 × 2.2 cylinders spanning the two hole sets.

- [ ] **Step 1: Write failing tests.**
  - `edgeCheck` 0/0. Peak z = 5.8 ± 0.05.
  - No overhang: for every triangle with a downward normal (nz < −0.01), all three vertices have z < 0.01, i.e. only the underside faces down.
  - Assembled: `overlapVolume(frameToAssembled(frame), lidToAssembled(lidShell))` < 1e-3. The pins' overlap with frame ∪ lid is < 1e-3.
  - Indexing: translate frame + pins together by 0.5 in x. `overlapVolume(pins, lid)` > 0.
  - Footprint ≤ 256 × 256.
- [ ] **Step 2: Run.** Expected: FAIL.
- [ ] **Step 3: Implement.** Sweep the profile with 260+ segments. Each strip is closed into a ring, and the profile is closed by the bottom strip. Weld the strips' shared corner vertices (identical positions) by index so `ofMesh` accepts it. **Do not** quantize-weld.
- [ ] **Step 4: Run.** Expected: PASS.
- [ ] **Step 5: Commit**, message "gift-box: moulded oval frame with dowel-pin holes".
