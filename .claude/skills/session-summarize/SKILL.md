---
name: session-summarize
description: Summarize a session so we can move to a fresh agent
---

Goal: Generate a summary that allows moving to another agent that can pickup new work.

Background: When working on a task with an agent, the context window can get full. It is often useful to summarize the current session and open up a new one.

SummGenerate a summary of the following:
- What we covered
- What we decided
- Where we left off
- What's next
